This is a sample post to show how to publish new articles.

To write a new one:

1. Add a file to `_posts/` named `YYYY-MM-DD-your-title.md`
2. Put the title in the front matter between the two `---` lines at the top
3. Write the rest in normal Markdown — headings, lists, code, images, all supported

```python
print("example code block")
```

That's it. Push to GitHub and Jekyll turns this into a page automatically, and
lists it on the [articles](/articles/) page too.
